# SAYSO

[🌐 SAYSO 바로 사용하기](https://orange-wave-06876f900.2.azurestaticapps.net)

## 앱 소개

**SAYSO**는 하고 싶은 말은 있지만 어떻게 표현해야 할지 어려울 때 도와주는 AI 메시지 작성 서비스입니다.

사용자는 상대방, 상황, 전달하고 싶은 내용, 원하는 말투만 입력하면 됩니다. SAYSO는 입력한 내용을 바탕으로 자연스럽고 상황에 맞는 메시지를 만들어줍니다.

작성된 문장은 보내기 전에 검사할 수 있고, 더 정중하게 또는 더 짧게 다시 고칠 수도 있습니다.

```text
작성 → 검사 → 개선 → 대화 저장
```

## 일반 AI와 다른 점

SAYSO는 아무 글이나 작성해주는 범용 AI가 아닙니다. 사람에게 메시지나 이메일을 보내는 상황에 집중해, 실제 소통 과정을 편하게 만드는 서비스입니다.

1. **프롬프트 없이 사용합니다.**

  어려운 AI 명령어를 직접 작성할 필요가 없습니다. 누구에게, 어떤 상황에서, 무슨 말을 하고 싶은지만 화면에 입력하면 됩니다.

2. **보내기 전에 문장을 검사합니다.**

  문장을 만든 뒤 바로 보내지 않고, 어색한 표현이나 무례한 표현, 부족한 정보, 오해할 수 있는 부분을 확인할 수 있습니다.

3. **상대방별 대화 방식을 관리합니다.**

  교수님, 회사 담당자, 상사처럼 상대방마다 이전 대화 내용과 주제를 저장할 수 있습니다. 다음에 연락할 때 이전 상황을 참고해 더 자연스럽게 이어서 작성할 수 있습니다.

4. **이야기를 준비하는 과정을 한 앱에서 관리합니다.**

  생각 정리, 메시지 작성, 문장 검사, 문장 개선, 복사, 대화 저장까지 여러 사이트를 옮겨 다니지 않고 SAYSO 안에서 처리할 수 있습니다.

5. **소통에만 집중된 AI입니다.**

  범용 AI처럼 모든 종류의 글을 다루는 것이 아니라, 메시지, 이메일, 문의, 요청처럼 사람과 이야기할 때 필요한 표현을 만드는 데 특화되어 있습니다.

## 어떤 사람이 사용하나요?

- 교수님이나 선생님께 연락해야 하는 학생
- 회사 담당자에게 문의해야 하는 취업 준비생
- 상사나 고객에게 메시지를 보내야 하는 직장인
- 학교, 회사, 기관에 자주 연락하는 사람

## 주요 기능

### 메시지 작성

상대방, 상황, 연락 목적, 전달할 내용, 원하는 말투를 입력하면 AI가 메시지를 만들어줍니다.

### 여러 표현 비교

한 번에 다음 세 가지 표현을 확인할 수 있습니다.

- 추천 표현
- 부드러운 표현
- 정중한 표현

### 보내기 전 문장 검사

작성한 문장을 다음 기준으로 확인합니다.

- 문장이 자연스러운지
- 필요한 정보가 빠지지 않았는지
- 너무 무례하거나 딱딱하지 않은지
- 상대방이 다르게 이해할 가능성이 있는지

### AI 문장 개선

다음 중 원하는 방향을 선택해 문장을 다시 고칠 수 있습니다.

- 더 정중하게
- 더 자연스럽게
- 더 짧게
- 덜 딱딱하게
- 더 명확하게

### 대화 관리

자주 연락하는 상대방과 최근 대화 내용을 저장할 수 있습니다. 저장한 내용은 다음 메시지를 작성할 때 다시 불러올 수 있습니다.

현재 대화 내용은 사용 중인 브라우저 안에 저장됩니다. 다른 컴퓨터나 다른 브라우저에서는 자동으로 보이지 않습니다.

## 사용 방법

1. [SAYSO 사이트](https://orange-wave-06876f900.2.azurestaticapps.net)에 접속합니다.
2. `새 메시지`를 선택합니다.
3. 상대방과 상황을 입력합니다.
4. 전달하고 싶은 내용을 입력합니다.
5. 원하는 말투를 선택합니다.
6. `SAYSO로 작성하기`를 누릅니다.
7. 마음에 드는 문장을 복사하거나 검사합니다.
8. 필요한 경우 AI로 문장을 개선합니다.
9. 다음에도 참고하고 싶다면 대화에 저장합니다.

## AI가 지키는 규칙

SAYSO는 문장을 만들 때 다음 원칙을 지킵니다.

- 사용자가 말하지 않은 사실을 마음대로 추가하지 않습니다.
- 날짜, 이름, 이유를 임의로 만들어내지 않습니다.
- 상대방과 상황에 맞는 말투를 사용합니다.
- 모든 문장을 지나치게 딱딱하게 만들지 않습니다.
- 사용자의 원래 의도와 내용을 최대한 유지합니다.

## 기술을 쉽게 설명하면

SAYSO는 화면과 AI 요청을 나누어 만든 웹앱입니다.

### 화면 부분

사용자가 보는 화면입니다. 홈, 메시지 작성, 문장 검사, 대화 관리 화면이 여기에 포함됩니다.

화면은 다음 기술로 만들었습니다.

- **HTML**: 화면에 글자와 버튼을 배치하는 역할
- **CSS**: 색상, 크기, 간격, 모바일 화면 디자인을 담당
- **JavaScript**: 버튼을 눌렀을 때 화면을 바꾸고 서버에 요청하는 역할

### 서버 부분

서버는 화면 대신 AI에게 질문을 보내고 결과를 받아오는 중간 역할을 합니다.

브라우저가 Azure OpenAI에 직접 접속하지 않도록 서버를 거치게 만들었습니다. 이렇게 해야 API 키를 사용자에게 노출하지 않을 수 있습니다.

### Azure Functions

Azure Functions는 서버를 계속 켜두지 않고, 요청이 들어올 때만 실행되는 작은 서버 기능입니다.

SAYSO에는 다음 네 가지 함수가 있습니다.

- `health`: 서버가 정상인지 확인
- `generate`: 메시지 작성
- `inspect`: 문장 검사
- `refine`: 문장 개선

### Azure Static Web Apps

Azure Static Web Apps는 HTML, CSS, JavaScript 파일을 인터넷에 공개해주는 Azure 서비스입니다. SAYSO의 화면이 이곳에서 제공됩니다.

### Azure OpenAI

Azure OpenAI는 사용자의 입력을 받아 메시지를 작성하고, 문장을 검사하고, 개선하는 AI 서비스입니다.

전체 흐름은 다음과 같습니다.

```text
사용자
  ↓
SAYSO 화면
  ↓
Azure Functions
  ↓
Azure OpenAI
  ↓
결과를 SAYSO 화면에 표시
```

## 환경변수란 무엇인가요?

환경변수는 비밀번호나 API 키처럼 공개하면 안 되는 값을 코드와 따로 보관하는 방법입니다.

API 키를 JavaScript 파일에 직접 적으면 누구나 볼 수 있기 때문에 안전하지 않습니다. SAYSO는 API 키를 서버에서만 읽도록 구성했습니다.

로컬에서 AI 기능을 사용하려면 다음 파일을 만듭니다.

```text
server/.env
```

`server/.env.example` 파일을 복사해서 만들 수 있습니다.

```powershell
Copy-Item server\.env.example server\.env
```

그다음 `server/.env`에 Azure OpenAI 정보를 입력합니다.

```env
AZURE_OPENAI_API_KEY=Azure에서_받은_키
AZURE_OPENAI_ENDPOINT=https://리소스이름.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=Azure에서_만든_배포이름
AZURE_OPENAI_API_VERSION=2024-10-21
PORT=3000
```

각 항목의 의미는 다음과 같습니다.

- `AZURE_OPENAI_API_KEY`: Azure OpenAI에서 발급받은 비밀 키
- `AZURE_OPENAI_ENDPOINT`: Azure OpenAI 리소스 주소
- `AZURE_OPENAI_DEPLOYMENT`: Azure에서 모델을 배포할 때 정한 이름
- `AZURE_OPENAI_API_VERSION`: Azure OpenAI가 사용할 API 버전
- `PORT`: 내 컴퓨터에서 서버를 실행할 번호

`server/.env`는 절대 GitHub에 올리면 안 됩니다. 이 파일은 `.gitignore`에 등록되어 있습니다.

## 내 컴퓨터에서 실행하기

### 1. Node.js 설치

Node.js는 JavaScript 서버를 실행하기 위한 프로그램입니다. 설치하면 `npm`이라는 패키지 설치 도구도 함께 설치됩니다.

[Node.js LTS 다운로드](https://nodejs.org/en/download)

### 2. 프로젝트 폴더로 이동

VS Code 터미널에서 실행합니다.

```powershell
cd C:\Users\WORK\Desktop\SAYSO
```

### 3. 필요한 프로그램 설치

```powershell
npm install
```

### 4. 서버 실행

```powershell
npm start
```

### 5. 브라우저에서 열기

```text
http://localhost:3000
```

Windows에서는 `run-sayso.bat` 파일을 더블클릭해도 됩니다.

## 프로젝트 폴더 설명

```text
SAYSO/
├─ public/                  사용자가 보는 화면
│  ├─ index.html            화면의 기본 구조
│  ├─ css/style.css         디자인 코드
│  └─ js/                   버튼과 화면 동작 코드
│
├─ server/                  로컬에서 사용하는 Express 서버
│  ├─ index.js              서버 시작 파일
│  ├─ routes/               메시지 생성·검사·개선 API
│  └─ lib/                  AI 연결과 프롬프트 코드
│
├─ api/                     Azure Functions 서버리스 API
│  ├─ host.json             Azure Functions 기본 설정
│  └─ src/functions/        generate, inspect, refine, health 함수
│
├─ package.json             필요한 프로그램 목록과 실행 명령
├─ Dockerfile               컨테이너 배포용 설정
├─ run-sayso.bat            Windows 실행 파일
└─ deploy-serverless.ps1   Azure 서버리스 배포 스크립트
```

## 개발 진행 과정

### 1단계: 기본 준비

Node.js 프로젝트를 만들고 Express 서버를 준비했습니다. 이 단계에서 로컬 서버를 실행할 수 있는 기본 구조를 만들었습니다.

### 2단계: 기본 화면 연결

브라우저에서 SAYSO 화면을 볼 수 있도록 `index.html`과 서버 연결을 만들었습니다. `/api/health` 주소로 서버가 살아 있는지도 확인할 수 있게 했습니다.

### 3단계: 화면 만들기

홈, 메시지 작성, AI 결과, 문장 검사, 대화 관리 화면을 만들고 메뉴를 눌러 이동할 수 있게 했습니다.

### 4단계: 입력 기능 만들기

상대방, 상황, 목적, 전달 내용, 말투를 입력할 수 있게 했습니다. 내용이 너무 짧거나 비어 있으면 안내 메시지가 나타납니다.

### 5단계: AI 메시지 작성 연결

Azure OpenAI와 연결하여 입력한 내용을 바탕으로 세 가지 메시지를 만들도록 했습니다.

### 6단계: 결과 기능 추가

AI 결과를 복사하고, 수정하고, 다시 생성하고, 문장 검사 화면으로 보낼 수 있게 했습니다.

### 7단계: 문장 검사 추가

문장의 자연스러움, 정보 부족, 예의 수준, 오해 가능성을 AI가 확인하도록 했습니다.

### 8단계: 문장 개선 추가

문장을 더 정중하게, 자연스럽게, 짧게, 부드럽게, 명확하게 바꿀 수 있도록 했습니다.

### 9단계: 대화 관리 추가

상대방과 최근 대화 내용을 브라우저에 저장하고 다시 불러올 수 있게 했습니다.

### 10단계: 서버리스 배포

로컬 서버를 Azure Functions로 옮기고, 화면은 Azure Static Web Apps에 배포했습니다. 이제 서버를 직접 계속 켜두지 않아도 인터넷에서 사용할 수 있습니다.

### 11단계: 배포 확인

다음 주소와 기능을 확인했습니다.

- SAYSO 화면 접속
- Azure Functions 상태 확인
- 메시지 생성
- 문장 검사
- 문장 개선
